# Learnova – Your Personalized Path to Success

## AI-Powered Personalized Learning Path Generator

Learnova is a smart education platform that generates personalized learning paths based on a learner's interests, current skill level, career goal, available daily learning time, and preferred learning duration.

The platform helps learners follow a structured roadmap with topics, practice activities, mini-projects, career milestones, study materials, and progress tracking.

---

## 🎯 Problem Statement

Learners often struggle to identify what to learn, in what order to learn it, and which resources to use for achieving their career goals.

Learnova addresses this problem by generating a structured and personalized learning path based on individual learner preferences and requirements.

---

## 💡 Solution

Learnova collects learner information such as:

- Learning interest
- Current skill level
- Career goal
- Daily available learning time
- Learning duration

Based on these inputs, the system generates a personalized learning roadmap with relevant topics, activities, projects, resources, and career milestones.
